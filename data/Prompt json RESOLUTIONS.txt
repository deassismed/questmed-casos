Você deve criar um arquivo JSON educacional para discussão de casos clínicos, seguindo rigorosamente a estrutura especificada abaixo.

OBJETIVO
Gerar um JSON válido, em português do Brasil, para material didático médico baseado em casos clínicos. O conteúdo deve ser adequado para estudantes de medicina, internos, residentes ou profissionais em formação clínica.

PÚBLICO-ALVO
Definir o nível como:
"Internato / Atenção Primária / Urgência / Clínica Médica / Especialidade relacionada"

ENTRADAS NECESSÁRIAS
Use as seguintes informações fornecidas:

1. Lista de casos clínicos

2. Tema central:
[SERÁ ENVIADO AO FINAL DESSA RECOMENDAÇÃO]

3. Objetivo educacional:
[DESCREVER O QUE O ESTUDANTE DEVE APRENDER]

4. Referências:
Usar preferencialmente diretrizes, consensos, revisões sistemáticas ou artigos científicos de boa qualidade.
Não inventar referências inexistentes.
Quando possível, incluir título, ano, URL e nota sobre a utilidade da referência.

REGRAS GERAIS

1. A saída deve ser exclusivamente um JSON válido.
2. Não incluir comentários fora do JSON.
3. Não usar markdown.
4. Não usar texto antes ou depois do JSON.
5. Usar aspas duplas em todas as chaves e strings.
6. Não deixar vírgula final após o último item de objetos ou arrays.
7. O conteúdo deve ser didático, técnico e clinicamente confiável.
8. A linguagem deve ser clara, objetiva e adequada ao ensino médico.
9. Evitar afirmações absolutas quando houver incerteza clínica.
10. Explicitar o raciocínio clínico, diagnóstico e terapêutico.
11. Diferenciar claramente os casos leves, moderados, graves ou com risco específico, quando aplicável.
12. Explicar por que a alternativa correta é adequada.
13. Explicar por que as alternativas incorretas não são preferíveis, quando houver alternativas.
14. Incluir recomendações de reavaliação, segurança clínica e descalonamento terapêutico quando o tema envolver tratamento.
15. Adaptar o conteúdo às melhores evidências disponíveis.

ORIENTAÇÕES DE PREENCHIMENTO

1. Campo "id"
Criar um identificador único, em minúsculas, sem acentos, com hífens entre palavras.
Exemplo:
"pneumonia-adquirida-comunidade-terapia-empirica-001"

2. Campo "caseIds"
Inserir os códigos dos casos clínicos discutidos.
Exemplo:
["ABC123", "DEF456", "GHI789"]

3. Campo "title"
Criar um título curto e descritivo.
Exemplo:
"Discussão sobre pneumonia adquirida na comunidade"

4. Campo "topic"
Descrever o tema específico do material.
Exemplo:
"Pneumonia adquirida na comunidade: estratificação de gravidade e terapia empírica"

5. Campo "opening"
Criar um parágrafo introdutório explicando o conjunto dos casos e o objetivo da discussão.

6. Campo "clinicalSections"
Criar três blocos progressivos:
- "Primeiras dicas": achados clínicos gerais e pistas iniciais.
- "Dicas intermediárias": diferenciação entre os casos.
- "Dicas PLUS": elementos avançados, fatores de risco, armadilhas diagnósticas ou terapêuticas.

Cada bloco deve conter três itens.

7. Campo "teaching.summary"
Escrever um resumo integrando todos os casos, suas diferenças clínicas e as condutas corretas.

8. Campo "learningObjectives"
Criar objetivos de aprendizagem, usando verbos como:
- Reconhecer
- Diferenciar
- Selecionar
- Justificar
- Identificar
- Evitar
- Aplicar

9. Campo "sections"

A seção "Dados clínicos completos dos casos" deve conter uma linha para cada caso clínico.
Cada linha deve incluir:
- Caso
- Dados clínicos explícitos
- Interpretação

A seção "Raciocínio diagnóstico" deve explicar como os dados clínicos levam ao diagnóstico e à estratificação.

A seção "Respostas dos casos" deve conter:
- Código e identificação do caso
- Resposta correta
- Justificativa clínica

A seção "Estratificação prática" deve transformar os casos em categorias clínicas úteis.

A seção "Critérios de gravidade úteis" deve listar achados clínicos, exemplos dos casos e sua interpretação.

A seção "Conduta por perfil clínico" deve organizar hipóteses, riscos ou agentes principais e conduta didática.

As seções do tipo "callout" devem funcionar como destaques explicativos para os principais grupos de casos.

A seção "Por que não as outras opções" deve explicar erros comuns, condutas inadequadas ou alternativas menos apropriadas.

A seção "Manejo prático" deve trazer passos aplicáveis à prática clínica.

A seção "O que evitar" deve listar armadilhas clínicas, diagnósticas ou terapêuticas.

A seção "Aplicação na prática" deve conectar cada caso à decisão clínica final.

A seção "Mensagem final para o estudante" deve encerrar com uma síntese didática.

10. Campo "references"
Incluir referências confiáveis.
Priorizar:
- Diretrizes clínicas
- Sociedades médicas
- Revisões sistemáticas
- Ensaios clínicos relevantes
- Artigos de revistas científicas reconhecidas

Cada referência deve ter:
- title
- year
- url
- note

11. Campo "deepDiveQuestions"
Criar cinco perguntas aprofundadas.
Cada resposta deve ser explicativa, clinicamente útil e coerente com o tema.

CRITÉRIOS DE QUALIDADE

Antes de finalizar, verificar:

1. O JSON é válido.
2. Todas as chaves obrigatórias estão presentes.
3. Não há comentários dentro do JSON.
4. Não há vírgulas finais inválidas.
5. As seções "table" têm "headers" e "rows".
6. As seções "bullets" têm "items".
7. As seções "callout" têm "content".
8. Os casos clínicos estão corretamente vinculados aos respectivos códigos.
9. As condutas estão justificadas.
10. As referências são reais e pertinentes.
11. O texto está em português do Brasil.
12. O conteúdo é adequado para ensino médico.
